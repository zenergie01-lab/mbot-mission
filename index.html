Comment jouer

1. Télécommande 🎮 : pilote le robot avec le clavier pour découvrir le circuit. Ensuite, clique sur « Transformer mes gestes en programme ».

2. Programme 🧩 : clique sur les blocs pour écrire le programme. Clique sur un bloc du programme pour le sélectionner : le prochain bloc s'ajoute juste après. Tu peux aussi glisser un bloc pour le déplacer.

3. Les étoiles : ⭐ réussi · ⭐⭐ programme presque aussi court que celui du prof · ⭐⭐⭐ aussi court ou plus court.

Règles du circuit :

  • 🧱 Mur : le robot s'arrête net s'il le touche.
  • 🚧 Barrière de couleur : elle s'ouvre seulement si les LED du robot ont la même couleur.
  • ↔ Passage étroit : impossible de tourner dedans. Utilise la marche arrière.
  • 🔋 Pile : passe dessus pour la ramasser. 📦 Colis : arrête-toi dessus et fais Bip pour le livrer.
  • 🚦 Feu : ne passe pas au rouge. 🌑 Tunnel : allume les LED en blanc pour y entrer.
  • ⬛ Ligne noire : dans certains niveaux, le robot ne doit pas la quitter.

Les blocs ont les mêmes noms que les cartes en papier. Le bouton « Pour le vrai mBot » traduit ton programme en blocs mBlock, avec des durées à régler.

Duel : course à la télécommande (ZQSD + AER pour les LED contre les flèches + KLM), ou duel de programmes avec un nombre de blocs limité.
